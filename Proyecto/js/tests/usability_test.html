🚗 Auto Motores - Pruebas de Usabilidad

1. Navegación Principal Alta Prioridad

Objetivo: Verificar que los usuarios pueden navegar fácilmente entre secciones

  • El logo lleva al dashboard principal
  • Los botones de navegación son claros y visibles
  • El botón "Volver" funciona correctamente
  • El botón "Cerrar sesión" es fácil de encontrar
  • La navegación es consistente en todas las páginas

2. Gestión de Órdenes de Trabajo Alta Prioridad

Objetivo: Evaluar la facilidad para crear y gestionar órdenes

  • El botón "Añadir" es visible y accesible
  • El formulario de nueva orden es intuitivo
  • Los campos obligatorios están claramente marcados
  • La búsqueda y filtros funcionan correctamente
  • Las acciones (Editar/Eliminar) son claras
  • La confirmación de eliminación previene errores

3. Gestión de Repuestos Media Prioridad

Objetivo: Verificar la usabilidad del inventario de repuestos

  • La información de stock es clara y visible
  • Los repuestos con stock bajo se destacan
  • La búsqueda por nombre funciona bien
  • Los botones de acción son del tamaño adecuado

4. Reportes e Impresión Media Prioridad

Objetivo: Evaluar la funcionalidad de reportes

  • El botón "Imprimir" es fácil de encontrar
  • La vista previa de impresión es clara
  • El formato de impresión es profesional
  • Los reportes muestran información relevante

5. Responsividad y Accesibilidad Baja Prioridad

Objetivo: Verificar que el sistema funciona en diferentes dispositivos

  • Las tablas se adaptan a pantallas pequeñas
  • Los botones son lo suficientemente grandes para tocar
  • El contraste de colores es adecuado
  • El texto es legible en todos los tamaños

6. Manejo de Errores Alta Prioridad

Objetivo: Evaluar cómo el sistema maneja errores y situaciones inesperadas

  • Los mensajes de error son claros y útiles
  • Los errores de login se muestran en la misma página
  • Los campos requeridos muestran validación
  • El sistema previene acciones destructivas accidentales
